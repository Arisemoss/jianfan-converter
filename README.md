# jianfan-converter

简繁转换 —— 文简书斋 · 电子书处理工具

一个纯前端、零构建、单文件的电子书文本处理工具。所有处理在浏览器本地完成，文件不会上传至服务器。

## 快速开始

直接用浏览器打开 [ebook-tool.html](ebook-tool.html) 即可，无需安装、无需构建。

## 功能

| 模块 | 说明 |
|---|---|
| 简繁转换 | 基于 [OpenCC](https://github.com/BYVoid/OpenCC)（opencc-js），支持 6 种方向：简↔繁、简↔香港繁体、简↔台湾正体 |
| 文本净化 | 清除空白行、合并多余空格、统一标点、清除特殊符号/网址/邮箱/零宽字符、Tab 转空格等 10 项 |
| 自定义去除 | 快速去除 HTML 标签/数字/英文/标点，或按行输入关键词 / 正则表达式批量删除 |
| 查找替换 | 对处理后文本进行查找替换，支持正则、区分大小写，可统计匹配数 |
| 批量处理 | 按当前设置批量处理多个文件并打包为 ZIP 下载（需网络加载 JSZip；无网络时逐个下载） |
| 撤销/重做 | 处理与替换操作可撤销（Ctrl+Z / Ctrl+Shift+Z），最多保留 50 步 |

### 其他特性

- **精确繁体字统计**：优先用 OpenCC 反向转换逐字对比；离线时回退到内嵌的 OpenCC 词典繁体字表（4000+ 字符）
- **深色 / 浅色主题**：一键切换，自动记忆偏好
- **设置持久化**：转换方向、勾选项、正则开关等保存在 localStorage
- **大文件友好**：超过 4000 行的文本分块处理，UI 不卡死，带实时进度
- **统计面板**：总字数、行数、段落数、中文字数、繁体中文字数、字母数字数
- **快捷键**：Ctrl+Enter 一键处理
- **编码提示**：检测到非 UTF-8 乱码时自动提醒

## 支持的文件格式

`TXT` `HTML` `HTM` `MD` `CSV` `JSON` `XML`

## 技术栈

- 原生 HTML / CSS / JavaScript，单文件零依赖
- [opencc-js](https://cdn.jsdelivr.net/npm/opencc-js@1.0.5) —— 简繁转换引擎（CDN）
- [JSZip](https://cdn.jsdelivr.net/npm/jszip@3.10.1) —— 批量打包（CDN，可选）

> 注意：OpenCC 与 JSZip 从 CDN 加载，首次使用需联网。核心处理逻辑不依赖网络；离线时 OpenCC 缺失则跳过转换并使用内置繁体字表统计。

## 隐私

所有处理（读取、转换、统计、下载）均在浏览器本地完成，没有任何文件或文本内容上传至服务器。
